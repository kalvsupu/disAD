# 截图清单（四张已就位，2026-11-22）

放进本目录、文件名**完全一致**，README 里就会自动显示。

| 文件名 | 拍什么 | 建议 |
|---|---|---|
| `screenshot-main.png` | 主界面：两张卡片都在运行中，数字不是 0 | 1080×2400 原图即可；把状态栏以下的整屏都带上 |
| `screenshot-notification.png` | 下拉通知栏，**只留 disAD 那一条**（已拦 N 次 · 已跳过 N 次 · 无障碍：已生效） | 可以裁掉其它 App 的通知，只留这一条 |
| `screenshot-skip.png` | 开屏广告正在被跳过：广告页 + 底部「已跳过 · 应用名」小提示 | 关键是能看清广告页和那条提示同屏 |
| `screenshot-ai.png` | 「AI 审查（实验）」卡片展开：地址 / Key（打码）/ 配置测试 / 修改模型 / 状态行 | **Key 一定要打码或先清空** |

可选的：

| 文件名 | 用途 |
|---|---|
| `screenshot-rules.png` | 「查看当前规则」弹窗（生效域名 / 关键字 / 作用范围） |
| `banner.png` | 仓库顶部大图（1280×320 左右），可不用 |

## 注意

- **不要出现真实 API Key**；如果状态行里有域名，也确认一下没有私人信息；
- 截图里如有通知栏时间、运营商等无关内容，不必刻意裁；
- 四张都在位时 README 会自动加载；换图时保持文件名不变即可，尺寸不必一致（README 里用 `width` 控制显示宽度）。
