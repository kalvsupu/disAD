# ========== E. 微信 / 小程序（2026-10-01 实机抓取）==========
# 抓取场景：微信 + 打开一个小程序 + 出现 2~3 个广告，全程只解析了 21 个域名。
#
# ★★ 关键发现：dns.weixin.qq.com.cn 是微信自带的 HTTPDNS。
#    微信的域名解析走它自己，**根本不经过系统 DNS** —— 广告域名是它自己解析出来的，
#    我们的 DNS 拦截自然一个都碰不到。这就是"微信广告一个都拦不住"的真正原因。
#
#    ⚠ 2026-10-01 决定：**不拦它**。
#      理由：拦掉它只是"逼微信回落系统 DNS"，收益不明确（QQ音乐实测下来，
#      广告最终是被无障碍点掉的，不是被拦掉的），但它会让微信失去防 DNS 劫持的能力，
#      在某些运营商网络下可能解析到被劫持的地址 —— 得不偿失。
#      同类还有 httpdns.kg.qq.com（QQ音乐）、wxa.wxs.qq.com（小程序数据上报），
#      都从拦截清单里移除了。
